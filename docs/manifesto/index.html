Inapoi la program

Manifest pentru servicii publice care respecta oamenii

Calendarul acesta exista fiindca informatia publica importanta este publicata intr-o forma greu de cautat, greu de verificat si greu de folosit pe telefon.

O administratie locala serioasa ar publica un API, date deschise versionate, fisiere usor de reutilizat si o experienta clara pentru cetateni. Nu ar trebui ca locuitorii sa sape prin tabele, PDF-uri vechi si pagini greu de parcurs ca sa afle cand se ridica gunoiul.

Votati oameni care cer servicii publice digitale curate, auditabile si utile. Incompetenta, clientelismul si indiferenta costa timp real din viata fiecarui cetatean.

Ce cerem

  • API public pentru programul de colectare, cu istoric si data ultimei actualizari.
  • Date oficiale pe strada, cartier, fractie, interval si sursa.
  • Notificari si export calendar fara conturi inutile.
  • Pagini accesibile, rapide, verificabile si prietenoase cu printul.

Pana atunci, acest proiect pastreaza trasabilitatea catre sursele oficiale RETIM si Primaria Arad.
