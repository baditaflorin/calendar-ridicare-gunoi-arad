# Postmortem: MVP Gunoi Arad

Date: 2026-05-03

## Summary

Built the first production-shaped MVP: Go backend, RETIM ETL, SQLite persistence, searchable UI, print view, ICS export, Prometheus metrics, Docker Compose, Nginx, local hooks, and smoke tests.

## What Went Well

- RETIM uses real HTML tables, so parsing with `goquery` is reliable enough for the MVP.
- The ETL extracts 1,599 real street/neighborhood rows from the live pages during smoke runs.
- Raw snapshots are stored before parsing, which makes future parser regressions reproducible.
- The UX now exposes real neighborhoods and real street names instead of forcing free-text guessing.
- Local tests cover normalization, fuzzy matching, parser fallback, and HTTP smoke endpoints.

## What Was Tricky

- The requested example street, Nicolae Densușeanu, appears explicitly for plastic/metal and bulky campaigns but not in the weekly residual/bio table. The MVP handles this by using exact street rows when available and only inferring missing fractions from the dominant neighborhood pattern with lower confidence.
- Disk space on the development machine was critically low during dependency compilation. Only local caches were cleared; no project files or source data were removed.
- The SQLite driver is `mattn/go-sqlite3`, so Docker builds need CGO. The Dockerfile contains that complexity in the builder stage.

## Current Risks

- RETIM can change table IDs or headers. Smoke tests should catch this before deploy.
- Inferred neighborhood events should be shown as lower-confidence data in future UI polish, not silently treated as official street-specific rows.
- `/metrics` is exposed through Nginx in the MVP. A real server may want network restriction.

## Follow-Up Work

- Add an admin/debug page for source hashes, row counts, parser issues, and inferred event counts.
- Render confidence labels in the UI for inferred cartier-level data.
- Add holiday handling and last-working-day adjustments if official sources mention them.
- Add support for Primaria Arad seasonal pages once their schedule format stabilizes.
